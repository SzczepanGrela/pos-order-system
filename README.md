# POS Order System

> **Date:** May 2024

A Windows Forms (C#) desktop application designed as a Point of Sale (POS) order management system. 

## Features
- Order creation and management
- Product and inventory handling
- User-friendly Windows desktop interface

## Technologies
- C#
- .NET Framework (WinForms)
